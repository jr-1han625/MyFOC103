# FOC 基本计算链验收

本页验收范围：两相 ADC 原始码换算电流 → Clarke → Park → d/q PI → 电压合成与矢量限幅 → 反 Park → SVPWM 占空比。实机开环角度与启动流程另见《首次试转与接线》；位置/速度闭环、无感观测器和电机模型前馈计算未实现。

当前已实现 TIM1、双 ADC 同步采样、零点平均和电压开环启动。完整电流 PI 链继续独立验收，尚未用于实机闭环。下面 12 V 数值案例的电流标度及 PI 增益不是硬件标定或整定值。

## 阅读入口

- `L2_Middleware/algos/foc_math.h/.c`：独立公式算子，标准 C99，无 STM32 外设依赖。
- `User/foc_control.h/.c`：电流环的唯一对象 `foc` 和整链入口 `Foc_ControlStep()`；实现中的 1～7 注释对应总框图。
- `User/main.c`、`User/stm32f10x_it.c`：现在用于自动开环试转；旧单步入口已移除，公式案例使用主机测试调用。
- `Validation/test_foc.c`：编译工程实际源码的数值验收，不另写一套被测算法。

现有显示/LED/按键/延时已按 A/B 能力接口拆到 `L1_Drivers`，L0 物理操作留在 `Hardware`，由 `User/driver_assembly.c` 静态绑定；详见同目录《驱动移植说明》。该拆分不改变本页 FOC 算子与数值验收案例。

## 统一约定

电流 A、电压 V、周期 s、电角度 rad。正相序 A/B/C，正电流流入电机。Clarke 幅值不变，q 轴超前 d 轴 90°。三相电流无零序，`Ic=-Ia-Ib` 是重构值，不能用于判断真实三相电流和是否为零。两相 ADC 必须来自同一有效 PWM 采样窗口；本模块无法从两个原始码判断采样时序是否正确。

`sample_angle_rad` 对应采样时刻；`output_angle_rad` 对应电压预计生效时刻。本电流环模块不生成角度、不估计速度，也不自行计算角度补偿；无补偿时由调用者把两者设为同一电角度。

## 公式与算子对照

| 步骤 | 本轮计算 | 实现 |
| --- | --- | --- |
| 电流换算 | `Ia=(raw_a-offset_a)*amp_per_count_a`，B 相同理；`Ic=-Ia-Ib` | `Foc_CurrentSample` |
| 标度 | `amp_per_count=Vref/(ADC满码*Rshunt*Gain)`，含电路正负极性 | 调用者填写标定结构体 |
| Clarke | `Ialpha=Ia`，`Ibeta=(Ia+2Ib)/sqrt(3)` | `Foc_Clarke` |
| Park | `Id=Ialpha*cosθ+Ibeta*sinθ`，`Iq=-Ialpha*sinθ+Ibeta*cosθ` | `Foc_Park` |
| 误差 | `ed=Id_ref-Id`，`eq=Iq_ref-Iq` | `Foc_ControlStep` |
| PI | `integral_trial=integral_previous+Ki*e*Ts`，`Vpi=Kp*e+integral_trial` | 两次 `Foc_PiStep` |
| 合成 | `Vrequested=Vpi+Vfeedforward`，基础链前馈填零 | `Foc_VoltageLimit` |
| 圆形限幅 | `Vlimit=utilization*Vdc/sqrt(3)`，`scale=min(1,Vlimit/幅值)`，两轴乘同一比例 | `Foc_VoltageLimit` |
| 抗饱和 | `integral_next=integral_trial+Vlimited-Vrequested` | 整链直接更新两轴积分状态 |
| 反 Park | `Valpha=Vd*cosθ-Vq*sinθ`，`Vbeta=Vd*sinθ+Vq*cosθ` | `Foc_InversePark` |
| 扇区判断 | 比较 alpha/beta 的方向与 0/60/120/180/240/300° 边界，得到扇区 1~6 | `Foc_Svpwm` |
| 有效时间 | `Vref*Tpwm=Vk*T1+V(k+1)*T2`，按所在扇区解二维方程 | `Foc_Svpwm` |
| 零矢量时间 | `t1=T1/Tpwm`，`t2=T2/Tpwm`，`t0=1-t1-t2` | `Foc_Svpwm` |
| 占空比分配 | 第一扇区 `Da=t1+t2+t0/2`，`Db=t2+t0/2`，`Dc=t0/2`，其他扇区按开关状态分配 | `Foc_Svpwm` |

限幅采用 SVPWM 线性区的内切圆，保留电压向量方向，不分别截断 d/q。`voltage_utilization` 范围 `(0,1]`，用于留出调制裕量，不等同于电流限制或过压保护。占空比语义为上桥臂有效导通比例，实际驱动极性、死区和比较寄存器换算由硬件驱动适配。

抗饱和采用离散单位增益跟踪回算，是本轮明确选择的实现。它校正下一周期的积分；本周期公开的 `pi_v` 仍表示回算前 PI 输出。未限幅时回算量为零。并未把这个回算关系隐含进 PI 公式，也未实现自动整定。

## 扇区算法的逐步验收

`Foc_Svpwm()` 是 `L2_Middleware/algos` 中的纯算法。它只接收 alpha/beta 电压、母线电压和结果指针，不包含业务头、不读取 `foc` 全局对象，也不操作定时器。`Foc_ControlStep()` 决定何时调用并持有结果。替换后的活动代码不再保留共模注入的另一套实现、三相参考电压或 `common_v` 字段。

以 A/B/C 上桥臂状态表示有效矢量：`V1=100`、`V2=110`、`V3=010`、`V4=011`、`V5=001`、`V6=101`，角度依次为 0/60/120/180/240/300°，幅值为 `2*Vdc/3`。

令 `a=1.5*Valpha/Vdc`、`b=(sqrt(3)/2)*Vbeta/Vdc`，解各扇区的有效矢量作用时间：

| 扇区 | 两条有效矢量 | t1=T1/Tpwm | t2=T2/Tpwm |
| --- | --- | --- | --- |
| 1 | V1、V2 | a-b | 2b |
| 2 | V2、V3 | a+b | -a+b |
| 3 | V3、V4 | 2b | -a-b |
| 4 | V4、V5 | -a+b | -2b |
| 5 | V5、V6 | -a-b | a-b |
| 6 | V6、V1 | -2b | a+b |

之后令 `t0=1-t1-t2`，将零矢量时间平均分给 `000`、`111`。每相占空比等于“该相在有效矢量中为 1 的时间比例”加 `t0/2`。代码两个 `switch` 分别展示作用时间计算与三相分配，可直接对照讲义第 02 课。

扇区理想区间为 `[0°,60°)` 至 `[300°,360°)`，零矢量用 `sector=0` 表示；非零向量在边界处的归属由浮点比较确定，相邻扇区的一个有效时间为零，输出应连续。只容忍 `2e-6` 周期的浮点边界误差，真正 `t1+t2>1` 时拒绝，不实现过调制。

结果输出的是归一化比例，真实秒值为 `T1=t1_ratio*Tpwm` 等；`Tpwm` 是硬件 PWM 周期，不一定等于电流环的 `period_s`。定时器中心对齐、互补输出、死区与实际边沿配置仍归硬件驱动，本算法不产生开关中断或 GPIO 时序。

## 可手算的整链案例

下面是独立主机验收的调用参数（`Validation/test_foc.c` 中已有对应测试）。不要在正在输出 PWM 的 MCU 上暂停并填写这些案例值。先调用 `Foc_Init()`，再赋值并调用一次 `Foc_ControlStep()`。

```c
foc.calibration.offset_a_count = 2048;
foc.calibration.offset_b_count = 2048;
foc.calibration.amp_per_count_a = 0.01;
foc.calibration.amp_per_count_b = 0.01;
foc.calibration.adc_max_count = 4095;
foc.gains_d.kp = 2;
foc.gains_d.ki = 10;
foc.gains_q.kp = 2;
foc.gains_q.ki = 10;
foc.period_s = 0.001;
foc.voltage_utilization = 0.9;
foc.reference_a.d = 0;
foc.reference_a.q = 2;
foc.feedforward_v.d = 0;
foc.feedforward_v.q = 0;
foc.enabled = 1;
FocSample sample = {2148, 1998, 12.0f, 0.0f, 1.57079632679f};
Foc_ControlStep(&sample);
```

这里故意采用不同的采样角和输出角，以验收两条角度路径；它们是人工数值输入。调用一次后检查 `foc`：

| 中间量 | 第一次计算的期望值 |
| --- | --- |
| `current_a` | `(1, -0.5, -0.5) A` |
| `current_ab_a` | `(1, 0) A` |
| `current_dq_a` | `(1, 0) A` |
| `error_a` | `(-1, 2) A` |
| `pi_d.integral_v`、`pi_q.integral_v` | `(-0.01, 0.02) V` |
| `pi_v`、`requested_v`、`limited_v` | `(-2.01, 4.02) V` |
| `voltage_limit_v`、`voltage_scale` | `6.235383 V`、`1` |
| `voltage_ab_v` | `(-4.02, -2.01) V` |
| `pwm.sector` | `4`，使用 V4=011、V5=001 |
| `pwm.t1_ratio/t2_ratio/t0_ratio` | `(0.357441, 0.290119, 0.352441)`，三者和为 1 |
| `pwm.duty_a/b/c` | `(0.176220, 0.533661, 0.823780)` |
| `status`、`valid` | `FOC_OK=1`、`1` |

第二次调用会继续积分，不应仍要求得到首次结果。重复首次案例前，先将 `enabled=0` 并调用一次清除积分，再使能并调用。主机调用的间隔不等于 1 ms，本例只是按 `Ts=0.001 s` 计算离散一步。

## 自动验收与证据

Windows 可直接运行 `Validation/foc_tests.exe`。有 clang、gcc 或 Zig 时可重新编译：

```powershell
python Validation/run_tests.py --cc "你的C编译器完整路径"
```

脚本按 C99、`-Wall -Wextra -Werror -pedantic` 编译实际的两个模块，在 `-O0`、`-O2` 下分别执行；编译命令、源码 SHA256 与结果写入 `Validation/test_results.txt`。编译器不使用 fast-math。临时下载的编译器和缓存在验证后清理，不作为项目依赖。

验收包含采样标度/极性/无效输入、720 个角度的三相正弦解析解、纯 q 轴和坐标往返、PI 两步递推、3-4-5 矢量限幅、六个扇区中心的解析时间与占空比、六个边界两侧的连续性、六边形顶点与超限拒绝、5 种幅值的有效矢量重构、占空比线电压重构与居中检查、整链案例、持续饱和与反向恢复、母线跌落、停机重启、NaN/溢出拒绝。线电压和居中条件共同验证新旧调制的占空比关系，不在固件中保留旧实现。另用独立零速 RL 模型进行 10,000 个控制步的电流闭环测试；该模型只在测试中存在。

主机测试不证明 F103 执行时间和真实电机控制效果。Keil 工程的目标构建记录在 `Validation/keil_build.log`，链接符号及大小可在 `Listings/Project.map` 查看。`Validation/before_foc.zip` 仅保存修改前的 `main.c` 和工程文件，作为本工程无 Git 时的恢复证据，不参与编译。

`Validation/before_sector_svpwm.zip` 保存扇区替换前源码及历史验证记录，其中的纯注释固件一致性记录只适用于先前注释修改。本次改动实际替换了算法和结果结构，当前数值结果以重新生成的 `test_results.txt` 为准。

## 输入失败与硬件接入边界

停机、无效周期/增益/利用率、无效 ADC 标度/码值、无效母线/角度和非有限计算结果都会返回非 OK 状态，清零积分及本周期中间结果，并将 `valid=0`。状态值：0 停机，1 成功，2 配置无效，3 采样/标度无效，4 数值计算失败。

失败时三相占空比置 0.5 仅作为数值中性值，不等于关断功率级。本数学链自身不提供功率级保护；目前开环启动业务已实现采样过流、母线阈值、FAULT 和时序异常关断，具体边界见《首次试转与接线》。失步和温度保护未实现。

将来投入电流闭环时，在 PWM 同步 ADC 采样完成入口提供完整 `FocSample` 快照，每控制周期调用一次 `Foc_ControlStep()`，成功后将三相占空比交给驱动。不要与现有电压开环业务同时争用 PWM。未使用延时补偿时两电角度相同；开环指令角度不能当作已测得的转子角度。
